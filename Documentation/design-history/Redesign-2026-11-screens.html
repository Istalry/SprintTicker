The model, the words and the states

The model, in one sentence, said once in first run (S3): one timer runs your task; when something interrupts you, ⚡ times it apart, one interruption after another; afterwards you place each one on a task, or keep it off the provider; time reaches the provider when you stop, after 10 s to undo. Every screen below is checked against this page: one meaning per word, one word per action, on every surface.

"Jira" in these screens stands for the user's provider. The app shows the provider's own name wherever the screens say Jira: Jira, OpenProject, or the name the user gave a custom provider (a server on the SprintTicker Provider API; the server's own name by default, e.g. "Forge Tracker"). A step the provider cannot do is not shown, never greyed: no assignment, no Done transition, no Fetch by key if its API has none. Keys follow the provider: MG-77 in Jira, #1234 in OpenProject.
