An API token is a unique key that lets apps and services securely connect to your BUSY Bar over the internet.

# Create an API token

1

In the web browser on your PC, go to [cloud.busy.app](https://cloud.busy.app)﻿

2

Log in to your BUSY account with your email address, or continue with Google, Apple, or Microsoft.

3

In the **API tokens** tab, click **\+ Create token**.

![Document image](https://images.archbee.com/3StCFqarJkJQZV-7N79yY/c6lTCPRKQ8EvI2v_BAR6L_busy-account-create-an-api-token.png?format=webp "Document image")

4

Enter the **Token name**, select **Access scope**, and click **Continue**.

The scope defines what the token can access — your entire account or a specific BUSY Bar (if you have one connected to your account).

5

Copy and save your API token.

﻿﻿![Inline image](https://images.archbee.com/3StCFqarJkJQZV-7N79yY/qnjdr5-ckAAHFovFCIo6c_danger-icon.png?format=webp) **Save your API token in a secure place**﻿

It is shown only once for security reasons, as anyone with the token can make requests on your behalf. If you lose it, you‘ll need to generate a new one.

# Rename a token

1

In the web browser on your PC, go to [cloud.busy.app](https://cloud.busy.app)﻿

2

In the **API tokens** tab, click the ﻿![Inline image](https://images.archbee.com/3StCFqarJkJQZV-7N79yY/_ScZ0XnFsOp19_kqii0gA_bi-edit-fill.png?format=webp) **Edit** icon next to the token you want to rename.

3

In the pop-up, enter the new name and click **Save**.

# Delete a token

﻿﻿![Inline image](https://images.archbee.com/3StCFqarJkJQZV-7N79yY/qnjdr5-ckAAHFovFCIo6c_danger-icon.png?format=webp) **Deleting a token is permanent**﻿

Once you delete a token, all requests using this token will stop working permanently. Any apps or services that rely on it will no longer work.

1

In the web browser on your PC, go to [cloud.busy.app](https://cloud.busy.app)﻿

2

In the **API tokens** tab, click the ﻿![Inline image](https://images.archbee.com/3StCFqarJkJQZV-7N79yY/cauoOCby4ZI9n81jwFS1R_bi-trash-fill.png?format=webp) **Delete** icon next to the token you want to delete.

3

In the pop-up, click **Delete token** to confirm the action.
