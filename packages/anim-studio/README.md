# Anim Studio

A scene editor for SprintTicker's full-screen BUSY Bar animations.

```bash
pnpm studio          # http://127.0.0.1:5180
pnpm test:studio
```

It composes a scene the way the bar's own animations are built: a rounded
plate with a two-colour gradient and an outline, an animated icon on the left,
and large text on the right. Each of those is a layer, and each can move on its
own. It exports the PNG sequence the app already plays, and can play the result
on a real bar.

**Read [STYLE-GUIDE.md](STYLE-GUIDE.md) before making an animation.** It records
what the official animations actually do, measured frame by frame: only the
icon moves, it moves smoothly rather than in whole-pixel steps, every action is
followed by a rest, and the loop ends on its first frame. The studio's features
exist to produce exactly that.

It is a separate package on purpose. It is Vite and plain TypeScript, with no
React and no Electron, so it keeps its own lifetime rather than following the
app's upgrade schedule.

## Scenes

A scene is `scenes/<id>.scene.json`: a size (72×16 for the whole front panel,
16×16 for an icon), a frame rate, a length in frames, and layers drawn bottom to
top.

| Layer | What it is | Can move |
| :--- | :--- | :--- |
| **Plate** | Rounded rectangle with anti-aliased corners, 2-colour gradient, a 1px outline graded top to bottom, and a highlight under the top edge | `slide` (the gradient drifts and returns), `pulse` (70–100% brightness) |
| **Icon** | Pixel sprite with its own palette, optionally frame by frame | Keyframed x, y, scale and opacity, with motion blur; frames before **loop from** play once |
| **Text** | One line in a pixel font, aligned in a box, with an optional gradient and a hard or soft shadow | Keyframed x, y and opacity; `typewriter`, `wave`, `shine`, `scroll`, `blink` |
| **Glow** | A soft ellipse that adds light (a halo) or tints towards a colour (a dark spot behind text) | Keyframed x, y, scale and opacity |

A new scene is 60 fps and 4 seconds long, like the official ones. Holds cost
nothing in the file, since `seq2anim` merges identical frames.

### Motion

An icon is drawn as pixel art and moved by **keyframes**, which is how the
official animations get their smooth falls, bounces and squashes
(STYLE-GUIDE.md §5).

- **Keying a value.** Each property shows its value at the playhead. ◇ sets a
  key there. Once a property has keys, editing its value sets a key at the
  playhead. With no keys, x and y just place the layer.
- **Easing.** Each key's easing says how the value leaves it:
  - ease in for a fall;
  - ease out for a landing;
  - overshoot for a squash recovering;
  - bounce for something dropped;
  - hold to jump.
- **Anchor.** Scale is applied about the anchor. Put it at the base for a
  squash and at the centre for a flip; a negative scale X is a mirror.
- **Motion blur.** It averages several instants within the frame, so a fast
  move smears along its path.
- **Anti-aliasing.** Everything is rendered 4 × 4 supersampled, so a sprite
  between pixels blends into both. At rest on whole pixels at scale 1, it comes
  out exactly as drawn.
- **Loop seam.** Under the timeline, the editor reports whether the frame after
  the last matches the first. A loop that does not close shows a twitch on
  every restart.

**Loop from** still works on the sprite's own frames. It is what lets a sprite
play an intro once and then repeat an idle cycle.

`period` is frames per cycle for every motion and effect except two:
`typewriter` counts frames per letter, and `scroll` frames per pixel.

Scene files are plain JSON with one string per sprite row, so they diff readably.
`parseScene` validates every field on load and on save. A scene the studio
writes can always be opened again, and a malformed colour never reaches the
device, where it would fail a whole draw.

### Fonts

| Font | Use |
| :--- | :--- |
| **Bold 9** | The one-line title face: 9px capitals with 2px stems, the height of the official single-word titles. Capitals, digits and `!%&'()+,-./:?` only; lowercase is drawn as capitals. |
| **Bold 7** | The two-line title face, same drawing at 7px: two lines fit the panel at y=0 and y=8. |
| **Sprint 5** | The app's row-0 face |
| **Sprint Small** | The app's row-1 face |

The two row fonts and Bold 7 are the app's own, imported in place from
`desktop-app/src/shared/fonts/`, not copied: the app draws its running timer in
Bold 7, and it cannot import from the studio. Bold 9 lives here, in
`fonts/sprint-bold-9.glyphs`. All four are generated by the same
`pnpm fonts:build`.

## Export

**Export** writes `Animations/<id>/<id>/frame_00000.png …` and `meta.json`,
which is the layout `AnimationPlayer` and `scripts/build-anims.js` already read,
so no other change is needed to play it. With **.anim** ticked it also compiles
`<id>.anim` with `scripts/busybar-anim-toolchain/seq2anim.py`, which needs
Python with Pillow and colorlog.

Three safeguards:

- **It refuses a folder holding files it did not write.** A frame set made any
  other way -- by hand, or restored from the firmware -- cannot be regenerated
  from a scene, and an id that happened to match one would otherwise overwrite
  it.
- **It deletes stale frames from a longer earlier export.** `seq2anim` compiles
  every PNG in the folder, so a leftover frame would play after the new ones.
- **Frames are named `frame_NNNNN.png`, with no other digit in the name.**
  `seq2anim` takes a frame's position from every digit in its filename, so
  `lunch_72x16_00003.png` would sort as frame 721600003.

## Previewing on the bar

**▶ On bar** compiles the scene exactly as an export would, uploads it, and
plays it on the front display. A monitor cannot show how the LEDs render
brightness, bleed and colour, so this is the real test of an animation.

- It draws under its own `application_name`, `sprintticker_studio`, so clearing
  the preview can never remove the app's elements.
- It draws at priority 100, above the app's 95. While the preview shows, the
  app's draws get 409, which the app already treats as "something else holds
  the display".
- The element carries a 5-minute timeout. A studio closed without **■ Stop**
  cannot leave the bar stuck on a preview. Closing the dev server also tries to
  clear it.
- The address defaults to `BUSYBAR_IP`, then to the USB address. It is checked
  with the app's own `isValidDeviceHost` before any request.
- The token field is never stored. Leave it empty to use `BUSYBAR_TOKEN` from
  the environment.

## How it is built

```
src/model/scene.ts      the scene format, its validation and sprite timing
src/model/motion.ts     keyframe tracks and easing curves
src/render/             the compositor: a pure function of (scene, frame)
src/ui/                 the editor, in plain DOM; store.ts owns all state and undo
server/api.ts           the local API: scene files, export, bar preview
server/export.ts        writes and compiles sequences
server/bar-preview.ts   upload, draw and clear, with the device injected
vite.config.ts          mounts server/api.ts on the dev server
```

**The compositor is deterministic.** `renderFrame(scene, frame)` has no clock,
no randomness and no state. The editor preview, the exporter and the tests all
call it, so what the editor shows is exactly what is exported.

**The server half is loaded through the dev server, not imported by the
config.** `vite.config.ts` loads `server/api.ts` with `ssrLoadModule`. A config
that imports TypeScript from across the workspace is what Vite's coming native
config loader cannot load, and it warned once per import on every start.

**The API refuses other origins.** Any page open in the same browser can send a
request to `127.0.0.1`, and this API writes into the repository and drives
hardware. A request whose `Origin` does not match the host is refused. The
server also binds to loopback only.

**The studio imports only from `desktop-app/src/shared/`.** Main would pull in
Electron and better-sqlite3, and the renderer would pull in React. ESLint
enforces this. The device calls go through `scripts/lib/busybar-device.js`,
which the hardware probe shares, so there is one copy of how to talk to the bar.
